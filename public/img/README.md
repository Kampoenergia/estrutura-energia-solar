# Imagens originais pendentes

Os arquivos de imagem da versão anterior não foram enviados.

Coloque aqui, com estes nomes:

- `estrutura-wordmark.png`: assinatura horizontal da marca.
- `estrutura-logo.jpg`: ícone/logo original.
- `hero-solar.jpg`: fotografia autorizada para o destaque da página.

O site verifica se os arquivos existem antes de utilizá-los. Sem eles, funciona com o nome da empresa em texto, um símbolo solar genérico e uma ilustração vetorial decorativa. Esses elementos não são apresentados como o logotipo oficial ou como fotos de instalações da empresa.

Não coloque documentos de clientes nesta pasta: ela é pública.
